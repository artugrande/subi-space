Aportar al treasury

Para empresas, agencias y cualquiera con USDT en Celo
  1. Tener USDT en Celo. No hace falta CELO para el gas.
  2. Aprobar el gasto al contrato del treasury.
  3. Llamar a deposit(monto, "tu atribución").
  4. El aporte queda con tu nombre en el ledger público.

B

Verificarte y cobrar el SUBI

Para cualquier persona con documento
  1. Escaneás tu documento con la app de Self. La prueba se genera en tu teléfono.
  2. El hub de Self valida la prueba y te da el alta: no hay otra puerta de entrada.
  3. El dividendo empieza a devengar desde ese momento.
  4. Llamás a claim() cuando quieras, sin apuro: el costo es el mismo.

C

Desde un agente, por MCP

Para agentes y herramientas de IA
  1. Apuntar el cliente a /api/mcp del proyecto.
  2. subi_status devuelve fondo, padrón y dividendo del día.
  3. subi_claimable y subi_registration consultan una dirección.
  4. subi_build_deposit y subi_build_claim arman la transacción sin firmar: el MCP no custodia nada.
Cómo conectarlo ↗

Dónde está parado el proyecto. El circuito completo funciona en Celo mainnet: los contratos están cableados, el padrón sólo se escribe tras una prueba de Self validada por su hub, y el treasury tiene fondos que el distributor puede repartir. Lo que falta para el piloto no es técnico: es sumar aportantes al fondo y cerrar el protocolo de evaluación con la universidad.

Correrlo local

# clonar y configurar

cd subi-concierge-agent && npm install

# correr los tests de los contratos

Desde un agente

El MCP, con los comandos exactos

SUBI expone su propio servidor MCP: seis herramientas sobre JSON-RPC 2.0. Las cuatro de lectura no necesitan llaves. Las dos de escritura devuelven la transacción armada y sin firmar, así que el servidor nunca custodia nada.

Todavía no está hosteado en una URL pública. Corre local con npm run dev y queda en http://localhost:3000/api/mcp. Lo digo acá para que nadie pierda tiempo buscando un endpoint que no existe.

Levantarlo

# clonar, instalar y levantar
git clone https://github.com/artugrande/subi-concierge-agent
cd subi-concierge-agent && npm install
npm run dev                      # MCP en /api/mcp, puerto 3000

Ver qué herramientas expone

curl -s -X POST http://localhost:3000/api/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Preguntar por el estado del fondo

curl -s -X POST http://localhost:3000/api/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"subi_status","arguments":{}}}'

Armar un cobro sin firmarlo

curl -s -X POST http://localhost:3000/api/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"subi_build_claim",
                 "arguments":{"address":"0x…"}}}'

Devuelve to, data, value y feeCurrency. Firmarlo es tu problema, y esa es la idea.

Conectarlo a un cliente MCP

{
  "mcpServers": {
    "subi": { "url": "http://localhost:3000/api/mcp" }
  }
}

Las seis herramientas

subi_statusSaldo del treasury, tamaño del padrón, distribuible y dividendo diario por persona.
subi_claimableCuánto tiene acumulado una dirección para cobrar ahora mismo.
subi_registrationSi una dirección está en el padrón y cuándo vence su prueba de vida. No expone el nullifier.
subi_contractsLas direcciones en Celo mainnet y los datos de la red.
subi_build_depositArma el approve y el deposit, sin firmar.
subi_build_claimArma el claim, sin firmar.
